# COMP588 project - McGill University
 Replicate the likelihoods and KLD of informed direct/factor deletion for MAR vs direct/factor deletion for MAR.

 Missing data is a widespread problem in both social and natural sciences. Some traditional methods exist to learn from missing data, such as maximum likelihood and multiple imputation. Newer methods have been developed after the introduction of missingness graphs, which represents the mechanism behind the missing data, in (Mohan, Pearl & Tian, 2013). One family of such new methods was introduced in the (Van den Broeck, Mohan, Choi, & Pearl, 2015) paper. In this paper, the authors found that their newly-invented algorithms scale better than the traditional ones. My project aims to replicate the results of this paper.

## References
 Mohan, K., Pearl, J., & Tian, J. (2013). Graphical Models for Inference with Missing Data. Advances in Neural Information Processing Systems 26 (NIPS 2013).

  Van den Broeck, G., Mohan, K., Choi, A., & Pearl, J. (2015). Efficient Algorithms for Bayesian Network Parameter Learning from Incomplete Data. Association for Uncertainty in Artificial Intelligence, 31. Amsterdam.
